    # GraphNodeMultiDiscrete

    Gym space for actions with graph node components.

    More precisely, some components are actually ids of observation graph nodes

    # Attributes

    • nb_graph_independent_components: number of action components that are independent of the graph. It will be the first components, the next ones are assumed to be graph nodes (identified by the node index).

    Constructor of :class:MultiDiscrete space.

    The argument nvec will determine the number of values each categorical variable can take. If start is provided, it will define the minimal values corresponding to each categorical variable.

    Args: nvec: vector of counts of each categorical variable. This will usually be a list of integers. However, you may also pass a more complicated numpy array if you'd like the space to have several axes. dtype: This should be some kind of integer type. seed: Optionally, you can use this argument to seed the RNG that is used to sample from the space. start: Optionally, the starting value the element of each class will take (defaults to 0).

  self,
      mask: tuple[MaskNDArray, ...] | None = None,
      probability: tuple[MaskNDArray, ...] | None = None
    ) -> NDArray[np.integer[Any]]

    Generates a single random sample from this space.

    Args: mask: An optional mask for multi-discrete, expects tuples with a np.ndarray mask in the position of each action with shape (n,) where n is the number of actions and dtype=np.int8. Only mask values == 1 are possible to sample unless all mask values for an action are 0 then the default action self.start (the smallest element) is sampled. probability: An optional probability mask for multi-discrete, expects tuples with a np.ndarray probability mask in the position of each action with shape (n,) where n is the number of actions and dtype=np.float64. Only probability mask values within [0,1] are possible to sample as long as the sum of all values is 1.

    Returns: An np.ndarray of :meth:Space.shape

    # HeteroGraphNodeMultiDiscrete

    Gym space multidiscrete actions with heterogeneous graph node components.

    More precisely:

    • some components are actually ids of observation graph nodes
    • the graph nodes can only be a subpart of the graph nodes corresponding to a given type of node.

    To node types are specified via binary node features. Each component can correspond to a different type of node, and thus will have a specific binary feature specified via its index among node features.

    # Attributes

    • action_components_node_flag_indices: node feature index, component by component, so that each corresponding action component will be the index of the chosen node among the nodes of the proper type, i.e. for which the specified node feature is equal to 1. For graph independent nodes, the node feature index must be None. (It must be the first components.)
